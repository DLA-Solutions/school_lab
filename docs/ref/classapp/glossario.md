# Glossary — ClassApp terminology

| Our term | ClassApp | Definition | Decision |
|----------|----------|------------|----------|
| profile | perfil | Student, staff, or container for access | `profile` |
| account | conta / usuário | Login (email/phone) linked to profiles | `user_account` |
| pending invite | convite pendente | Invitation not yet accepted | `pending_invite` |
| channel | canal | Scoped messaging or attendance queue | `channel` |
| announcement | comunicado | Broadcast message | `announcement` |
| moment | momento | Feed-style media post | defer or `moment` |
| charge | cobrança | Payment request via ClassPay | `receivable` |
| payment product | ClassPay | Embedded payments module | `payment_gateway` |
| enrollment campaign | campanha de matrículas | Online enrollment funnel | `enrollment_campaign` |
| arrival | Cheguei | Pickup/arrival tracking product | `check_in` |
| CSAT | avaliação CSAT | Satisfaction score on channels | `satisfaction_rating` |
| tag | tag / etiqueta | Audience segmentation for messages | `tag` |
