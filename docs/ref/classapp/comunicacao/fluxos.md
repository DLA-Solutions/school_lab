# Flows — communication (ClassApp)

Harvest: 2026-08-14.

## Invite guardian to student profile

**Actor:** administrator  
**Preconditions:** profile exists; valid email or phone

1. Open school menu → People/Channels → select profile → **Accounts**.
2. Click **Add email** or **Add phone** (not for fixing existing contacts — use **Change contact**).
3. Optionally set tags; enable **Send invite after adding**.
4. Submit; ClassApp sends invite; track as **pending** until accepted.

Source: [Contas](https://ajuda.classapp.com.br/hc/pt-br/articles/52854108543131)

## Send a message

**Actor:** staff or guardian (within channel rules)

1. Open Conversations or target channel.
2. Compose message (formatting, attachments optional).
3. Send; recipients receive push/email per notification rules.

Source: [enviar mensagem](https://ajuda.classapp.com.br/hc/pt-br/articles/19673522008475)

## Configure attendance channel (ticket mode)

**Actor:** administrator

1. Open channel settings.
2. Choose **simple** vs **with attendance status**.
3. Set routing and SLA visibility; enable CSAT if desired.

Source: [canais de atendimento](https://ajuda.classapp.com.br/hc/pt-br/articles/19673522008475)

## Year rollover — update roster (ERP-integrated school)

**Actor:** administrator  
**Preconditions:** active ERP integration (vendor-specific)

1. Follow integration-specific article (Sponte, Gennera, ActiveSoft, or internal view).
2. Run student update/import job.
3. Verify accounts and pending invites.

Source: integration articles under Integrações category.
