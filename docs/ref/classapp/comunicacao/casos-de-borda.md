# Edge cases — communication (ClassApp)

Harvest: 2026-08-14.

## Pending invite ≠ no access

A pending invite on one profile does not mean the person lacks ClassApp access globally —
they may already use other profiles/channels.
([Contas](https://ajuda.classapp.com.br/hc/pt-br/articles/52854108543131))

## Duplicate users

Adding email/phone instead of **Change contact** creates duplicate accounts — docs warn explicitly.

## 2FA lockout

Separate troubleshooting for guardians vs administrators; code not received flows documented.

## ERP sync divergence

Each ERP integration (Sponte, Gennera, ActiveSoft, view) has distinct update steps —
schools on wrong integration article will fail silently or call support.

## Mandatory CPF update

Regulatory cadastral campaign blocks or nags users until CPF validated; edge cases for invalid CPF.

## Channel vs conversation confusion

Schools must choose channel type upfront; switching types affects attendance tracking and CSAT.

## LGPD / external access

Dedicated help section — external file access and data subject rights require admin configuration.
