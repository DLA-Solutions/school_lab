# Flows — financial (ClassApp)

## Onboard ClassPay bank account

**Actor:** administrator (financial)

1. Access ClassPay setup wizard.
2. Register institution bank account (KYC/docs per article).
3. Enable charge sending.

Source: [primeiros passos ClassPay](https://ajuda.classapp.com.br/hc/pt-br/articles/19673522008475)

## Manage delinquency

**Actor:** financial staff

1. Menu **Receitas → Inadimplências**.
2. Apply filters (class group; include/exclude disabled students).
3. Review KPIs and aging charts.
4. **Notify delay** — bulk or per student; or open student profile for direct contact.

Source: [inadimplentes](https://ajuda.classapp.com.br/hc/pt-br/articles/1260804719849)

## Send charge via ClassApp

**Actor:** administrator

1. Create charge linked to student/guardian.
2. Guardian pays via app (boleto/card per configuration).
3. Track confirmation and settlement in ClassPay dashboard.

Source: [enviar cobrança](https://ajuda.classapp.com.br/hc/pt-br/articles/19673522008475)
