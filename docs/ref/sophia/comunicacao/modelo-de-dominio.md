# Domain model — communication (Sophia)

Harvest: 2026-08-14.

## Guardian portal (`Terminal Web`)

Configurable portal modules: notices, financial status, boleto print, class files, etc.
([gestão escolar](https://sophia.com.br/sophia-gestao-escolar/))

## Self-service cadastral edit

Guardians/students update own registration data via web portal.

## WhatsApp Web integration

Both desktop and web Sophia lines integrate WhatsApp Web for outreach.

## Support occurrences

Área do Cliente lists support tickets (`ocorrências` with vendor) — not school-family messaging.
