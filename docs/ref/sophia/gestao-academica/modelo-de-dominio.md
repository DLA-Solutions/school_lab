# Domain model — academic (Sophia)

Harvest: 2026-08-14. Marketing sources only.

## Entities (inferred)

### Teacher workspace

Web **Ferramenta Professor**: grades, didactic content, attendance, homework, occurrences.
([gestão escolar](https://sophia.com.br/sophia-gestao-escolar/))

### Student performance

Individual, class-group, and subject-level views; tracks guardian/student portal access
and material consumption.

### Occurrence (`ocorrência`)

Pedagogical/disciplinary events from teacher tool.

### Enrollment / capture

**Captação de Alunos**, contracts, documents, email to prospects; **Gestor de Vendas**
linked to RD Station opportunities.

### Re-enrollment

Electronic signature via **Clicksign** integration — remote contract signing.

### Document generation

Microsoft Word merge for personalized documents.
