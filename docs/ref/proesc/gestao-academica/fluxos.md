# Flows — academic management (Proesc)

Harvest: 2026-08-14.

## Configure enrollment trail (matrícula / rematrícula online)

**Actor:** admin  
**Preconditions:** Configurações > Acadêmico > Pré-matrícula; boleto generation on

1. Set entity code, logo, document upload requirements.
2. Configure contract text (plain paste — formatting warnings).
3. Optionally require multiple signers (financial, avalista, pedagogical guardians).
4. Test with sample student name.
5. For rematrícula: ensure next exercício exists before sending trail.

Source: [trilha de matrícula](https://suporte.proesc.com/hc/pt-br/articles/17165116960279)

## Execute matrícula (secretariat)

**Actor:** secretariat  
**Preconditions:** cadastros complete, turma available

1. Secretaria → Matrículas → Lista de matrículas.
2. Confirm enrollment and assign payment plan.
3. Send trilha via WhatsApp or email for signature/payment.

Source: [realizar matrículas](https://suporte.proesc.com/hc/pt-br)

## Teacher: launch diary and grades

**Actor:** teacher  
**Preconditions:** professor linked to disciplina/turma

1. Open diário for class/subject.
2. Create lessons (including individual lessons when needed).
3. Launch grades on activities or assessment periods.
4. Record attendance.

Source: [Professor category](https://suporte.proesc.com/hc/pt-br)

## Coordination: monitor diary delivery

**Actor:** coordinator  
**Preconditions:** Proesc Analytics enabled

1. Open Analytics → Diários.
2. Review delivery counts by month, bimestre, exercício.

Source: [Proesc Analytics](https://suporte.proesc.com/hc/pt-br/articles/360056436834)

## Transfer student between class groups

**Actor:** secretariat  
**Preconditions:** active matrícula

1. Use reclassificar aluno de turma workflow.
2. Verify débito impact (related articles warn about orphan charges).

Source: [reclassificar turma](https://suporte.proesc.com/hc/pt-br)

## Year-end rollover

**Actor:** admin / secretariat  
**Preconditions:** exercício nearing end

1. Follow checklist de fim de ano (diary closure, reports, rematrícula prep).
2. Run relatório de alunos não rematriculados by unidade.

Source: [finalização de ano letivo category](https://suporte.proesc.com/hc/pt-br)

## Hide subject from boletim

**Actor:** coordination  
**Preconditions:** disciplina on turma

1. Edit disciplina settings on turma.
2. Mark “ocultar disciplina do boletim”.

Source: [ocultar disciplina](https://suporte.proesc.com/hc/pt-br/articles/360056436834)
