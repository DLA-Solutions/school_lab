# Flows — communication (Proesc)

Harvest: 2026-08-14.

## Publish institution comunicado

**Actor:** staff (secretariat/coordination)  
**Preconditions:** Proesc Agenda module active

1. Create comunicado in ERP (staff article cluster).
2. Comunicado appears as banner in app Comunicados section.
3. Optionally allow likes/comments.

Source: [criar comunicado](https://suporte.proesc.com/hc/pt-br)

## Open private recado thread

**Actor:** guardian or staff  
**Preconditions:** app login / staff permissions

1. Guardian or staff opens Agenda → new message.
2. Thread persists in agenda de recados.
3. Push notification sent to guardian app.

Source: [Proesc Agenda overview](https://suporte.proesc.com/hc/pt-br/articles/16533531345431)

## Record daily routine

**Actor:** teacher / infant staff  
**Preconditions:** rotina module enabled

1. Enter meals/behavior collectively by turma or per student.
2. Save — triggers push to guardian.

Source: [criar rotina escolar](https://suporte.proesc.com/hc/pt-br)

## Guardian views boletim in app

**Actor:** guardian  
**Preconditions:** grades published

1. Open Boletim e notas in app.
2. View detail; download PDF.

Source: [Proesc Agenda overview](https://suporte.proesc.com/hc/pt-br/articles/16533531345431)

## Enable Proesc Agenda module

**Actor:** admin + vendor  
**Preconditions:** commercial activation

1. Request module from Proesc (per overview CTA).
2. Configure staff permissions and guardian access articles.
3. Families install app and complete login article flow.

Source: [utilizar módulo Proesc Agenda](https://suporte.proesc.com/hc/pt-br)

## Guardian switches child context

**Actor:** guardian (multi-student)  
**Preconditions:** multiple matrículas linked

1. Tap user icon top-right.
2. Select matrícula — all tabs refresh.

Source: [Proesc Agenda overview](https://suporte.proesc.com/hc/pt-br/articles/16533531345431)
