# Domain model — communication (Agenda Edu)

Harvest: 2026-08-14. Sources: [help center](https://atendimento.agendaedu.com/hc/pt-br).

## Entities

### Multichannel inbox

**Message channels** (real-time chat with families) vs **attendance channels** (ticket queues
with defined response hours and end-of-service CSAT). Both audited and LGPD-aligned per marketing.
([comunicação multicanal](https://www.agendaedu.com/comunicao-multicanal))

### Announcement (`comunicado`)

School broadcasts with filtering; guardian read tracking.

### Team group (`grupo de conversa`)

Internal staff groups separate from family-facing channels.

### Photo wall (`mural de fotos`)

Album-based media sharing.

### Poll (`enquete`)

Survey to guardians/students.

### Event / calendar (`evento` / `calendário`)

Events with optional attendance confirmation.

### Notification center

Centralized push/email preferences; can disable email receipt notifications.

### Shop (`Shop`)

In-app commerce for school products/offers.
