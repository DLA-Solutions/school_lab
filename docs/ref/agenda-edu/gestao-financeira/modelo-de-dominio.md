# Domain model — financial (Agenda Edu Pagamentos)

Harvest: 2026-08-14.

## Entities

### Charge plan (`plano de cobrança`)

Template for recurring or one-off school charges; ERP vs Manual setup paths.

### Charge (`cobrança`)

Statuses documented in dedicated article (pending, paid, overdue, etc.).
([status cobranças](https://atendimento.agendaedu.com/hc/pt-br/articles/360022393913))

### Enrollment-linked billing (`matrícula` tab)

Payments menu integrates enrollment/rematricula with charge creation.

### Remittance file import

Send charges from bank remittance file — bridge for schools with external ERP.

### Pix checkout (`novo checkout`)

SuperApp checkout redesign — high documentation callout count (friction signal).

### Fee schedule

Public article on Agenda Edu fees/taxes.
