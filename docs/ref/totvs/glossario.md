# Glossary — TOTVS Educacional terminology

| Our term | TOTVS | Definition | Decision |
|----------|-------|------------|----------|
| student | aluno | Enrolled learner in institution | `student` |
| enrollment | matrícula | Academic and financial linkage | `enrollment` |
| class group | turma | Student cohort for scheduling and grades | `class_group` |
| report card | boletim | Published academic results | `report_card` |
| guardian portal | portal do aluno / portal cliente | Self-service for grades, NF, boleto | `guardian_portal` |
| service invoice | NFS-e | Municipal service tax document | `service_invoice` |
| AVA integration | ambientes virtuais de aprendizagem | LMS coupling for EaD | integration PRD |
| AI assistant | Carol | RM Educacional support bot in portal | defer |
| school network | redes de ensino | Multi-unit operator | `school_network` |
