# Flows — academic management (Sponte)

Harvest: 2026-08-14. Marketing-level happy paths; step counts approximate.

## Year-start academic planning

**Actor:** pedagogy coordinator / secretariat  
**Preconditions:** new school year created

1. Register courses and curriculum matrices.
2. Build digital class diaries per course/subject.
3. Organize teacher timetables.
4. Generate lesson plans.
5. Run seating allocation from enrollment counts.

Source: [gestão pedagógica](https://www.sponte.com.br/gestao-pedagogica)

## Configure evaluation model

**Actor:** school admin (often with vendor onboarding)

1. Choose numeric, conceptual, or skills-based model.
2. Set recovery and period rules.
3. Customize report card and transcript layouts in document editor.

Source: [gestão pedagógica](https://www.sponte.com.br/gestao-pedagogica)

## Teacher: record attendance and grades

**Actor:** teacher  
**Preconditions:** school-issued ERP credentials

1. Access Sponte ERP (web).
2. Open class diary for class/subject.
3. Record lesson, grades, and absences.

Escalation: invalid login → secretariat only (not vendor) per FAQ.
Source: [suporte](https://www.sponte.com.br/suporte)

## Guardian: view grades

**Actor:** guardian or student  
**Preconditions:** school portal URL, login, published grades

**Portal (desktop):**
1. Open school-specific Portal do Aluno URL from secretariat.
2. Log in with school-provided credentials.
3. Select “Notas”.

**Agenda Plus (mobile):**
1. Install app; log in with registered email.
2. On first access: set password, verify email code, accept terms.
3. Tap “Notas” on home menu.

Source: [suporte](https://www.sponte.com.br/suporte), [portal do aluno](https://www.sponte.com.br/portal-do-aluno)

## Online assessment delivery

**Actor:** teacher → student  
**Preconditions:** basic-education segment (not language schools)

1. Publish assessment online via ERP.
2. Student completes via Portal do Aluno.
3. System calculates grade; syncs to portal/app.

Source: [gestão pedagógica](https://www.sponte.com.br/gestao-pedagogica)

## Lead → enrollment (capture module)

**Actor:** marketing / secretariat  
**Preconditions:** capture module enabled

1. Run capture campaigns (forms, follow-up).
2. Convert lead to enrollment in secretariat module.

Source: [captação](https://www.sponte.com.br/captacao)
