# Flows — academic management (KAITS)

Harvest: 2026-08-14.

## 1. Configure evaluation and curriculum (year start)

**Actor:** school academic staff  
**Preconditions:** Institution segment configured (e.g. educação básica)

1. Define evaluation system: grades and/or concepts; bimestre or trimestre.
2. Set up curriculum matrix for automated boletim/contract generation.
3. Customize report outputs (boletins) per school branding.

Source: [educação básica](https://kaits.com.br/sistema-para-escola-educacao-basica/)

## 2. Plan and assign lessons

**Actor:** academic coordinator / secretariat  
**Preconditions:** Teachers, rooms, and class groups defined

1. Schedule lessons on institutional calendar (color-coded views).
2. Assign teachers; monitor room occupancy.
3. Apply cancellation rules when needed; register makeup lessons.

Source: [homepage](https://kaits.com.br/), [escola de idiomas](https://kaits.com.br/sistema-para-escola-de-idiomas/)

## 3. Register daily routine (early childhood)

**Actor:** teacher  
**Preconditions:** Student enrolled; parent portal/app access enabled

1. Update virtual agenda with day-to-day notes and activities.
2. Record occurrences on students.
3. Publish menu/nutrition info to portal when school provides meals.

Source: [escola infantil](https://kaits.com.br/sistema-para-escola-infantil/)

## 4. Record class diary and grades

**Actor:** teacher  
**Preconditions:** Lessons scheduled; evaluation periods open

1. Enter lesson content in class diary.
2. Record partial/final grades or concepts.
3. System generates pedagogical reports (frequency, grade analysis, atas).

Source: [homepage](https://kaits.com.br/), [educação básica](https://kaits.com.br/sistema-para-escola-educacao-basica/)

## 5. Online enrollment (new student)

**Actor:** prospective student/guardian  
**Preconditions:** Classes published; online enrollment enabled

1. Choose class/turma.
2. Complete registration and payment.
3. Accept contact/terms online (`aceite de contato`).
4. Flow variant: adult vs infantil personalization.

Source: [homepage](https://kaits.com.br/), [escola de idiomas](https://kaits.com.br/sistema-para-escola-de-idiomas/)

## 6. Language-school placement

**Actor:** prospect or academic staff  
**Preconditions:** Leveling module enabled

1. Run online leveling assessment.
2. Store proficiency test results on student record.
3. Assign appropriate class/package based on level.

Source: [escola de idiomas](https://kaits.com.br/sistema-para-escola-de-idiomas/)

## 7. Corporate partner monitoring

**Actor:** empresa conveniada manager  
**Preconditions:** Employees enrolled; partner access granted

1. Log into partner-scoped portal.
2. View customized attendance and performance reports per employee.
3. Use data for corporate–school relationship management.

Source: [escola de idiomas](https://kaits.com.br/sistema-para-escola-de-idiomas/)

## 8. Library loan

**Actor:** librarian / student  
**Preconditions:** Catalog with barcodes; reader registered

1. Register or identify reader (carteirinha).
2. Scan item barcode; create loan record.
3. Track return; MEC-compliant catalog in higher-ed context.

Source: [homepage](https://kaits.com.br/), [ensino superior](https://kaits.com.br/sistema-para-ensino-superior/)

## 9. Online document acceptance

**Actor:** student/guardian  
**Preconditions:** Document issued in system

1. Receive document (contract, terms, etc.).
2. Accept digitally via integrated online acceptance.
3. School stores acceptance for audit.

Source: [homepage](https://kaits.com.br/), [ensino superior](https://kaits.com.br/sistema-para-ensino-superior/)

## 10. Guardian/student portal access

**Actor:** student, parent, or teacher  
**Preconditions:** School branding configured; optional embed on school website

1. Log in to white-label portal (or App KAITS).
2. View grades, boletins, contracts, messages, and optionally finance.
3. Request second boleto copy when finance module enabled.

Source: [homepage FAQ](https://kaits.com.br/)

## 11. Franchise network oversight

**Actor:** franchisor admin  
**Preconditions:** Network/franchise module active

1. Access exclusive franchisor area.
2. Review real-time dashboards and unit KPIs.
3. Plan expansion from performance indicators.

Source: [redes e franquias](https://kaits.com.br/sistema-para-redes-e-franquias/)
