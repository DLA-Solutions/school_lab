# Glossary — ClipEscola terminology

| Our term | ClipEscola | Definition | Decision |
|----------|------------|------------|----------|
| message board | Agenda de recados / Mural Virtual | School-to-family announcements | `announcement` |
| daily routine | Diário da criança / Ficha do bebê | Infant daily care log | `daily_routine` |
| virtual diary | Diário do professor virtual | Teacher daily class record | `class_diary` |
| payment module | ClipPag | Automated dunning + mobile payments | `payment_collection` |
| e-signature credits | ClipCoins | Consumable credits for digital signatures | defer metering design |
| digital signature | Assinatura Eletrônica | Enrollment/contract signing workflow | `document_acceptance` |
| lead capture | gestão de leads / matrícula online | CRM + online enrollment funnel | `lead`, `online_enrollment` |
| ERP integration | API aberta / 70+ parceiros | Sync with external academic/finance systems | `erp_integration` |
| check-in | Controle de entrada e saída | Student arrival/departure tracking | `check_in` |
