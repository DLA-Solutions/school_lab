# Scholar Premium marketing site — review evidence

Generated by `npm run evidence` after a production build (`npm run build`).

## Artifacts

- Viewport captures at 320, 390, 768, 1440, and 1920 CSS pixels
- Reduced-motion and WebGL-fallback states
- Mobile (3×) and desktop Lighthouse JSON reports
- `runtime-summary.json` — verification gates and performance targets
- `runtime-history.json` — last 10 evidence runs for stability comparison

## Residual gaps (always reported)

- Physical Safari, iOS Safari, and Android Chrome are not exercised by the headless harness
- Lighthouse mobile throttling is simulated
- Lab interaction latency is not field INP
- Scene frame timing uses SwiftShader in headless Chrome; not a substitute for physical GPU review

Run evidence twice before release review to confirm stable mobile LCP samples.
